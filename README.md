# CyberHeal AI downloads

Windows installers for the CyberHeal AI desktop app, which watches Ubuntu servers over SSH. Get the newest version from **[Releases](https://github.com/rrhaha78-rgb/CyberHeal-Release/releases)**.

- CyberHeal runs on Windows 10 and 11 (64-bit).
- Beta builds aren't code-signed yet, so Windows SmartScreen shows "Windows protected your PC". Each release lists the installer's SHA-256 checksum, so you can check the download before you run it.
